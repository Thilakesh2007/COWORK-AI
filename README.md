# COWORK AI 🤖

**Your personal AI assistant, built to work locally on your computer.**

COWORK AI is a Python-based personal AI assistant powered by [Ollama](https://ollama.com/) and Google's Gemma model. The project aims to create a capable, personalized assistant that can understand natural language, remember useful information across conversations, research the web when needed, and gradually expand into helping with real tasks on your computer.

## ✨ Features

- **Local AI inference:** Run an AI model locally through Ollama.
- **Persistent personal memory:** Save personal facts, preferences, and other useful information separately from chat history.
- **Conversation history:** Preserve recent conversations across sessions.
- **Automatic memory detection:** Recognize supported personal facts and preferences without relying entirely on the language model to invoke a tool.
- **Selective web research:** Search the web when current or external information is needed, rather than for every message.
- **Tool integration:** Extend the assistant with functions such as calculations, web searches, and memory management.
- **Response timing:** Measure response time to help evaluate performance.
- **Privacy-conscious design:** Keep the core assistant and its memory files on your own computer.

## 🛠️ Technology Stack

- Python
- Ollama
- Gemma 4
- DuckDuckGo search through `ddgs`
- JSON-based persistent storage

## 🚀 Project Vision

The long-term goal is to evolve COWORK AI into a versatile desktop assistant that can understand requests, use personal context, research information, work with local files, and assist with multi-step computer tasks—with appropriate user control and safeguards.

COWORK AI is an evolving project, built incrementally with an emphasis on useful memory, practical tool use, local execution, and reliability.

## 📌 Current Status

Under active development. Features and capabilities will expand as the project progresses.
